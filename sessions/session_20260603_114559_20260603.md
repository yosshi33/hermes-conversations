### User (2026-06-03 11:58:55 UTC)

Codex の Sites は、OpenAI が 2026年6月に発表した新機能で、**「アイデアや指示から、共有可能なWebサイトやWebアプリを自動生成する機能」**です。 

例えば、

* ランディングページ
* 社内ポータル
* ダッシュボード
* シミュレーター
* プロジェクト管理サイト
* イベント特設ページ
* 顧客向けの提案サイト

などを、自然言語で指示するだけで作成できます。 

イメージ

あなたの場合なら、

「企業向け金融教育サービス『マネスク』の紹介サイトを作って。
福利厚生EXPO向けで、サービス説明、導入メリット、問い合わせフォーム、QRコード掲載。」

と入力すると、

* デザイン
* HTML/CSS
* インタラクション
* レスポンシブ対応

まで含めたサイトを Codex が生成し、そのままURLで共有できるようになります。 

ChatGPTのCanvasとの違い

Canvasは「文章やコードを編集する作業スペース」ですが、

Sitesは

「完成したWebサイトやWebアプリとして公開する仕組み」

に近いです。 

誰向け？

もともと Codex は開発者向けでしたが、現在は

* マーケター
* 営業
* デザイナー
* コンサルタント
* 企業の企画担当

など、プログラミングができない人でも使える方向に進化しています。
