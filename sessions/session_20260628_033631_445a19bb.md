## 原因：Reply Token の有効期限切れ

LINEでは、メッセージが届いてから**約60秒間しか使えないReply Token**が発行されます。この間に応答を返せるとReply API（無制限）で送信できますが、時間がかかるとPush API（月間上限あり）にフォールバックし、429で失敗します。

**実例（本日の記録）：**

| 送った内容 | 処理時間 | 結果 |
|-----------|---------|------|
| 「こんにちは」 | 10秒 | ✅ Replyで成功 |
| 「宜しく」 | 7秒 | ✅ Replyで成功 |
| 「あれ？返事がない」 | 13秒 | ✅ Replyで成功 |
| 「ここ一週間で学んだ情報を教えて」（1回目） | 119秒 | ❌ Token切れ→Push429 |
| **「ここ一週間で学んだ情報を教えて」（2回目）** | **13秒** | **✅ 成功（キャッシュ効いた）** |
| →「動いたり動かなかったりだなぁ」 | 12秒 | ✅ Replyで成功 |

つまり、**すぐ答えられること（簡単な質問）は届くが、調べが必要なこと（調査依頼、長期記憶検索）は届かない**という状態です。

## 根本解決

LINE Developersコンソールで**アクセストークンを再発行**し、**月間Push上限の状況を確認**するのが確実です。もし無料プランで上限が低い場合は、プラン変更も選択肢になります。

ただ、**Reply APIが使えればPush APIは不要**なので、別の対策として「即レス＋後送」方式も可能です（まず「少々お待ちください」と返してから、後で結果を送る）。

対処方法を選べます：
1. **LINE Developersでトークン再発行＋Push上限確認**（確実）
2. **「即レス＋後送」の仕組みを導入**（当面の回避策）
3. **両方やる**（推奨）

## 原因

`LINE_SLOW_RESPONSE_THRESHOLD=0` が設定されていたため、**「時間がかかる処理のときに「回答を見る」ボタンを出す機能」が完全に無効化されていました。**

これにより：
- 短い処理（10秒以内）→ Reply APIで届く ✅
- 長い処理（60秒以上）→ Reply Token期限切れ → Push APIにフォールバック → 429月間上限で失敗 → **返事が来ない** ❌

## 修正した内容

`.env` ファイルに以下を設定しました：

```
LINE_SLOW_RESPONSE_THRESHOLD=30
LINE_PENDING_TEXT=🤔 調べています。準備ができたら下の「回答を見る」をタップしてください 👇
LINE_BUTTON_LABEL=回答を見る
```

**30秒以上かかる処理の場合：「回答を見る」ボタンがLINEに送られます。** それをタップすると、回答が届く仕組みです。

   ```

   ```

2. **手動で再起動する場合**: サーバー管理画面からhermes-agentコンテナを再起動

再起動は数秒で完了し、LINE接続は自動で復旧します。再起動していただけますか？
