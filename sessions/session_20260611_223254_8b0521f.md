**【発表内容】**
Googleが2026年6月9日、新しい音声翻訳モデル「Gemini 3.5 Live Translate」を発表。人間の同時通訳に近いリアルタイム音声翻訳を目的としたモデル。

**【主な技術的特徴】**
- 話し終わりを待たず、数秒の遅延で継続的に翻訳音声を生成するストリーミング方式
- 話し手のイントネーション・ペース・ピッチを維持した自然な合成音声で訳出
- 文脈を待つか即時訳出するかのトレードオフを動的に調整する適応型処理
- 70以上の言語を自動検出（手動設定不要）
- 騒音環境に対応するノイズ耐性を搭載
- 全生成音声に電子透かし「SynthID」を埋め込み

**【対応プラットフォーム・タイムライン】**
- 一般向け：Android/iOS「Google翻訳」アプリで順次展開
- 企業向け：Google Meetで一部法人向けプライベートプレビュー開始。年内広範ロールアウト
- 開発者向け：Gemini Live API / Google AI Studioでパブリックプレビュー

**【対応言語】**
70以上。1会議内で2000以上の言語ペア対応（従来は英語⇔5言語のみ）。

**【留意点】**
- 具体的な価格は非公表
- Meetの一般提供は「年内」予定

マスター、鋭い指摘です。

まさに日本語同時通訳の最大の難所です。SOV構文＋否定/肯定が文末に来るため、訳者が文頭から肯定で訳し始めて最後に「ない」と来ると全部やり直し、になります。

人間の同時通訳士は「予測補償」や「文節チャンク分割」で対応しますが、AIの場合は記事にある「文脈を待つか即時訳出するかを動的に調整」という機構がこの問題への回答になります。

ただ現実問題として、日本語⇔英語の同時通訳精度は他の欧州言語間より難易度が圧倒的に高く、このモデルがそこをどこまで解決できているかは実際に使ってみないと分からない部分です。Google翻訳アプリに順次展開されているので、出たら試す価値がありますね。
