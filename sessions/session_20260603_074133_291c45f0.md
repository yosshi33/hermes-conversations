**口碑（実際のユーザー報告）**

Hermes Desktopはv0.15.0（5月28日）と一緒に出たばかりで、**まだ初期段階**です。GitHub Issuesに上がっている不具合・反応：

- **Windows**: 管理者権限がないとインストール失敗。rolldownモジュールが見つからないエラーも報告あり
- **Linux Wayland**: チャット画面がフリッカー（点滅・jumping）するバグ。回避策なしと報告
- **スクロールバグ**: 長い回答で表示が飛ぶ問題が複数報告され、開発チームが活発に修正中

コミュニティの反応は「出たばかりでバグ多いけど、開発スピードは速い」的な状況です。

**サーバー型との違い**

Desktop App（新）:
- Electron製のGUIアプリ、手元のPCにインストール
- macOS / Windows / Linux対応
- i18n対応（英語＋簡体字中国語、今後他言語追加予定）
- 個人利用・手軽さ重視

サーバー型（従来・マスターが使っている方式）:
- Docker/SSHでサーバーに常駐
- LINE・Discord・Telegramなどメッセング経由で操作
- cron自動化、バックグラウンドタスク、24/7稼働に向く
- CLI（TUI）で操作

結論：個人の手元でチャット的に使うならDesktop、24時間自動化・LINE連携したいならサーバー型、という棲み分けです。マスターの今の環境（Docker+LINE連携）はサーバー型が正解なので、今のままで問題ないですよ。
