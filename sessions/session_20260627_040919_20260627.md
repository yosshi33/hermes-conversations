結論から言うと、NotionがPowerPoint（.pptx）を作れるようになったのは、**2026年6月25日発表の「Notion Developer Platform」** の一部です。

### 要点

**何ができるのか**
- `createPresentation` というWorkerツールで、Notionページの内容を読み取り、自動でPowerPointファイル（.pptx）を生成
- 各見出しがスライドになり、生成されたファイルはページに自動アップロードされる
- TypeScriptでカスタムツールとして記述可能（pptxgenjs使用）

**一緒に発表されたもの**
- **External Agents**: ClaudeやCursorなどの外部AIエージェントをNotion内で@メンション呼び出し
- **Workers**: Notion上で動くサーバーレス関数（Cloudflare Workersベース）
- **Notion CLI / MCP / Webhooks**

**現状の制限**
- PowerPoint（.pptx）のみ確認。Word/ExcelはWorkerで自作すれば可能だが、テンプレートとしての提供はまだ確認できず
- 現時点では開発者向けが中心（一般ユーザー向けのワンクリック出力ではない）
