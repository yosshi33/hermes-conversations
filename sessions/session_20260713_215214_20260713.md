### 実務で直ちに適用すべきルール

あなたの環境で今日から使える対策です。

| 対策 | 具体的な実装 |
|---|---|
| **削除禁止** | `rm` コマンド禁止は既に記憶に保存済み。継続推奨。 |
| **承認プロセス** | 削除・上書き・権限変更を伴う処理は、マスターの確認後に実行する設計に。 |
| **最小権限** | cron jobの `workdir` を限定し、エージェントが触れるフォルダを制限。 |
| **対象不在時の動作** | プロンプトに「見つからない場合は停止し、勝手に代替を選ばず報告せよ」と明記。 |
| **ログ取得** | 操作ログを必ず残す設定。Hermesのcron実行ログは `process(action='log')` で取得可。 |
| **サンドボックス検証** | 新規ワークフローは本番反映前に必ず隔離環境でテスト。 |
