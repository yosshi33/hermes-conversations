マスター、結論から言うと、住宅ローン相談は「お客様の全体像を整理する」から始め、「条件比較・本申込・金消契約」の順に進めるのが定石です。

## 住宅ローン相談の進め方（6ステップ）

**Step 1: お客様の全体像をヒアリング**
最初に以下の情報を整理します。ここを飛ばすと後で手戻りが発生します。

| 項目 | 確認ポイント |
|------|-------------|
| 年収（税込） | 給与収入か事業収入か。残業代含むか。 |
| 勤続年数 | 3年以上が安定と見られやすい。転職直後は審査落ちリスク。 |
| 頭金 | 物件価格の何%用意できるか。0%でも通るが金利優遇が減る。 |
| 借入希望額 | 年収の5〜7倍が目安（金融機関による）。 |
| 他ローン残債 | カードローン・車ローン・奨学金は返済負担率に響く。 |
| 物件種別 | 新築/中古/建売/注文住宅。中古は築年数で融資不可になるケースあり。 |
| 勤務先 | 上場企業・公務員は金利優遇を受けやすい。 |

**Step 2: 希望条件を明確化**
- 変動金利 vs 固定金利 vs 固定期間選択型
  - 変動：今は低いが将来の変動リスクあり
  - 全期間固定：安心だが金利が高い
  - 固定期間選択（10年固定など）：バランス型、最も選ばれる
- 団信（団体信用生命保険）の有無
  - ワイド団信・三大疾病団信など特約付きの選択肢も提示

**Step 3: 複数金融機関で仮審査を出す**
- お客様の属性に合った金融機関を2〜3行ピックアップ
- 「1行だけ」は絶対避ける。比較させないと「他に良い条件があったのでは」と後悔を残す。
- フラット35も選択肢として提示（金利は変動より高いが、全期間固定で安心）

**Step 4: 仮審査結果を比較表で提示**
- 金利（実質年率）
- 毎月返済額
- 総返済額
- 諸費用（事務手数料、印紙代、登記費用、保証料）
- 団信の内容
→ お客様は数字でしか判断できないので、「総返済額が一番少ないもの」を基準に説明するのが合理的。

**Step 5: 本審査→契約**
- 仮審査通過後、必要書類を揃えて本審査へ
- 本審査通過後、金消契約（金銭消費貸借契約）を結ぶ

**Step 6: 実行（物件引渡し）**
- 融資実行日＝物件の引き渡し日。売主・司法書士と日程調整。

## 現場で押さえておくべきポイント

1. **「頭金0%でも通りますか？」は必ず確認**
   - 最近はフルローンも増えているが、金融機関ごとに基準が違う

2. **団信の告知義務**
   - 持病があると団信に加入できないケースがある（持病があれば事前に確認）
   - 団信に入れない場合、金利が上がったり融資不可になるケースもある

3. **繰上返済の話は最後に**
   - 「毎月の返済が楽になるから」と変動一択にするお客様には、団信や将来の金利上昇リスクをセットで説明

4. **契約前に必ず「ライフプランシミュレーション」を**
   - 子どもの教育費・老後資金まで含めたキャッシュフローを見せると、納得度が格段に上がる
